Temuan dokumentasi resmi FONNTE (2026-10-21):

- Device Edit dapat mengubah nama, webhook, dan autoread; token disalin melalui tombol Token pada daftar device. https://docs.fonnte.com/device/
- Token API harus disimpan aman karena pemilik token dapat mengirim pesan melalui WhatsApp. https://docs.fonnte.com/token-api-key/
- Webhook device menerima incoming chat. Dokumentasi update device memakai field webhook, webhookconnect, dan webhookstatus. https://docs.fonnte.com/api-update-device/
- Dokumentasi bahasa Inggris menyatakan verifikasi webhook terbaru memakai POST saja, bukan GET dan POST. https://docs.fonnte.com/language/en/
